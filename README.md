# Projet BTDemande

## Description
Ce projet est dédié à l'intégration et à la gestion des fonctionnalités liées à l'affichage du mot de passe dans les formulaires de connexion.

## Installation
Pour installer le projet, suivez les étapes ci-dessous :
1. Clonez le dépôt : `git clone https://github.com/alex368/btdemande.git`
2. Accédez au répertoire du projet : `cd btdemande`
3. Installez les dépendances si nécessaire.
